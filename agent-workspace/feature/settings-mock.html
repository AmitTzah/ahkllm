Command Reference
What are commands?
Commands appear in the backtick menu — press the backtick key (`) to open it. Each command sends selected text (or your input) to an LLM model and returns the response. You can group commands into submenus with tags, assign keyboard shortcuts, and customize every aspect of how they work. The app ships with several built-in commands — you can edit, delete, or create your own.
Required Fields
commandName — Internal identifier, not shown to the user.
menuText — Label in the backtick menu. & sets an accelerator key (e.g. &1 - My Command lets user press 1).
APIModels — Model to use. Supports provider/model (e.g. openai/gpt-4o) or short name (e.g. deepseek-v4-flash).
Prompt Composition
systemMessage — System prompt text. Supports {{selection}}, {{fullText}}, {{input}}.
systemMessageFile — Path to .txt file with system prompt. Takes precedence over systemMessage.
userMessage — Template for user message sent to the LLM. Same template variables. Use backtick-n (``n) for newlines, not \n.
showInputBox — Opens a text box before sending. User's input → {{input}} variable.
inputBoxDefault — Text pre-filled in the input box. Only meaningful with showInputBox.
Template Variables
{{selection}} — Text the user highlighted before triggering the command.
{{fullText}} — The entire document text (read via Windows accessibility API).
{{input}} — What the user typed in the input box (only if showInputBox is on).
Work in systemMessage, systemMessageFile, and userMessage. Ignored in FIM mode. If no templates or userMessage are set, selected text is sent as-is (legacy behavior).
Response Handling
pasteMode — chat (chat window), replace (overwrites selection), append (after cursor). Default: chat.
stream — Real-time token-by-token output. Requires pasteMode: chat.
temperature — Sampling temperature 0–2. Higher = more creative. Empty = model default.
maxTokens — Max tokens in response. FIM commands should set this (default: 4000).
stop — Array of stop sequences (e.g. ["\n\n"]). Generation stops on match.
Thinking (Reasoning)
thinking — { type: "enabled"|"disabled", level?: "low"|"medium"|"high"|"xhigh" }
"enabled" works across all providers (translated per API). Level defaults to "medium". Leave empty for model default.
FIM (Fill In the Middle)
isFIM — Uses DeepSeek FIM beta endpoint instead of chat completions. When true, all prompt fields above are ignored.
FIM Fill (pasteMode: replace) — fills gap between prefix and suffix. Works with or without selection.
FIM Continue (pasteMode: append) — continues from cursor/selection.
expandNewlines — Expands single \n to \n\n (standard LLM paragraph break). Useful for FIM/prose.
maxContextWords — Max words of surrounding context. FIM Fill: splits above/below cursor. FIM Continue: controls before-cursor capture. 0 = no limit.
Menu Organization
tags — Array of submenu names. Each tag creates a submenu containing all commands with that tag.
directAccelerator — Keyboard shortcut for commands inside tagged submenus. Press backtick then the key (e.g. &r) to fire directly. Only useful with tags.
